Язык сравнений

Операторы сравнения в Python

hp = 75 boss_hp = 100 print(hp == 75) # True (равно) print(hp != boss_hp) # True (не равно) print(hp > 50) # True (больше) print(hp < 50) # False (меньше) print(hp >= 75) # True (больше либо равно)
== (два знака)

Проверка точного равенства: 5 == 5 -> True.

!= (восклицательный)

Проверка неравенства: 5 != 3 -> True.

Логический ответ

Результат любого сравнения — это всегда либо True (правда), либо False (ложь).

Срабатывает, если игрок угадал код с первого раза.
