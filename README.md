# Чат-боты на Python: система для занятий в классе

Инструкция для учителя и администратора класса: что поставить, как скачать проект на учительский ПК,
как подключить компьютеры учеников и что делать в день занятия.

## Как это устроено

```
 Учительский ПК (сервер курса)                Компьютеры учеников
 ┌────────────────────────────────┐           ┌──────────────────────────┐
 │ kurs_server.py  ← порт 8000    │◀── сеть ──│ ярлык «Курс» → VS Code    │
 │ пульт: localhost:8000/teacher  │  класса   │ с панелью курса справа    │
 │ ключ GigaChat (с занятия 3) ───┼──▶ интернет└──────────────────────────┘
 └────────────────────────────────┘
```

- **Сервер курса** работает на учительском ПК (или на любом компьютере в той же сети, см. раздел 7).
  Он хранит группы, задания, результаты и работы учеников и раздаёт панель для VS Code.
- **Ученикам** нужны только Python и VS Code. Проект им скачивать не нужно: всё приходит с сервера.
- **Интернет** нужен только учительскому ПК и только для нейросети (занятия 3–8). Занятия 1–2 идут без интернета.

## 1. Что нужно заранее (один раз, делает администратор)

| Где | Что | Проверка |
|---|---|---|
| Все ПК | **Python 3.8 или новее** (лучше 3.10+). На Windows при установке отметить «Add python.exe to PATH» | `python3 --version` (Windows: `py --version`) |
| Все ПК | **VS Code** (обычная установка, расширения не нужны) | VS Code открывается |
| Все ПК | одна локальная сеть: ученические ПК «видят» учительский | `ping IP-учительского-ПК` |
| Учительский ПК | входящие подключения на **порт 8000** разрешены в брандмауэре | см. раздел 3 |
| Учительский ПК | интернет и ключ GigaChat (к занятию 3) | см. раздел 5 |

pip, Node.js, venv и права администратора на ученических ПК **не нужны**.

## 2. Скачать на учительский ПК

**Вариант А — архивом.** Откройте https://github.com/qwerty-ll/chatbots-kurs → зелёная кнопка **Code** → **Download ZIP**.
Распакуйте в удобную папку, например `~/chatbots-kurs` (Windows: `C:\chatbots-kurs`).

**Вариант Б — через git (удобно обновлять):**

```bash
git clone https://github.com/qwerty-ll/chatbots-kurs.git ~/chatbots-kurs
```

**Вариант В — без интернета.** Скопируйте папку на флешке с компьютера, где она уже есть.

Что в папке:

```
kurs/server/     сервер курса, пульт учителя, шлюз к нейросети
kurs/client/     установщик для компьютеров учеников и сборка панели
kurs/vscode/     панель ученика для VS Code
kurs/checker/    проверка заданий
kurs/tasks/      задания занятий 2–8, теория, тетради уроков
kurs/content/    шпаргалка
Код/             ai.py и agent.py — панель сама кладёт их ученикам
Презентация/     presentation.html — слайды всех 8 занятий (двойной щелчок, клавиша N — заметки)
```

## 3. Первый запуск сервера

Откройте терминал в папке проекта и запустите:

```bash
python3 kurs/server/kurs_server.py
```

На Windows (в «Командной строке» или PowerShell, в папке проекта): `py kurs\server\kurs_server.py`.

Сервер напишет:

```
Панель для учеников собрана: версия 0.1.0.
Сервер курса запущен …
  Страница учителя:  http://localhost:8000/teacher
  Адрес для учеников: http://192.168.1.10:8000
  Остановить: Ctrl+C
```

Окно терминала **не закрывайте** до конца урока: закроете окно — сервер остановится.

**Брандмауэр.** Windows при первом запуске спросит «Разрешить доступ» — разрешите для частной сети.
На Linux с ufw: `sudo ufw allow 8000/tcp`. Проверка: на ученическом ПК откройте в браузере адрес для учеников —
должна открыться страница сервера.

**Пульт учителя.** Откройте http://localhost:8000/teacher в браузере **на учительском ПК** (с других компьютеров
пульт не открывается — так задумано).
1. При первом входе придумайте пароль учителя (забыли — `python3 kurs/server/kurs_server.py --reset-password`).
2. **«Новая группа»** → название и список учеников (по одному имени в строке).

Данные сервера (группы, результаты, работы, ключ нейросети) лежат в `~/.kurs-server/`, отдельно от проекта:
обновление проекта их не трогает. Другой порт: `--port 8080`, другая папка данных: `--data ПУТЬ`.

## 4. Подключить компьютер ученика (один раз на каждый ПК)

1. Запустите сервер (раздел 3) и откройте пульт. Пока занятие не начато, на пульте есть блок
   **«Как подключить компьютер ученика»** с готовой командой — в ней уже стоит правильный адрес сервера.
2. На ученическом ПК откройте терминал и вставьте эту команду. Она выглядит так:

```bash
wget -T 10 -qO- http://192.168.1.10:8000/k | python3 - --shortcut
```

   macOS: `curl -sm 10 http://192.168.1.10:8000/k | python3 - --shortcut`.
   Windows: `py -c "import urllib.request as u; exec(u.urlopen('http://192.168.1.10:8000/k', timeout=10).read())" --shortcut`.
   Если команда сразу закончилась и ничего не написала — связи с учительским ПК нет: на компьютере ученика
   в браузере должен открываться адрес сервера (раздел 9).

Что делает команда:
- ставит панель курса в **отдельный профиль** VS Code (`~/.kurs/`): обычный VS Code на этом компьютере не меняется;
- создаёт папку `~/Курс` и ярлык **«Курс»** на рабочем столе;
- при каждом запуске ярлыка сама обновляет панель с сервера (переустанавливать после обновлений не нужно).

Если домашняя папка ученика очищается после перезагрузки (так бывает в компьютерных классах вузов),
команду нужно выполнять перед каждым занятием или добавить её в автозапуск.
Убрать курс с компьютера: `python3 ~/.kurs/kurs_start.py --uninstall`.

Проверка: двойной щелчок по ярлыку «Курс» → открывается VS Code, справа панель со списком имён
(если занятие уже начато) или надпись «Занятие ещё не началось».

## 5. Нейросеть (нужно к занятию 3, настроить можно заранее)

Ученики **ничего не вводят**: ключ один, он хранится только на учительском ПК. Панель сама кладёт ученику
`ai.py` и `.env` с временным ключом класса (он перестаёт работать после урока).

1. Получите **ключ авторизации GigaChat API** в личном кабинете на developers.sber.ru
   (для физлиц — тариф с scope `GIGACHAT_API_PERS`). Ключ — длинная строка, похожая на набор букв и цифр.
2. Пульт (карточка видна и до начала занятия) → **«🤖 Нейросеть»** → **«Настройки»** → вставьте ключ, модель **GigaChat** (самая быстрая для класса) → сохранить.
3. **«Проверить связь»** — должен прийти короткий ответ.

Если «Проверить связь» пишет про сертификат: скачайте сертификат **«Russian Trusted Root CA»**
(НУЦ Минцифры, gosuslugi.ru/crt) и укажите путь к файлу в тех же «Настройках».

Во время урока на пульте видно очередь и ленту «Что спрашивают у нейросети». Если нейросеть недоступна —
**«Запасной режим»**: ученики получают заготовленный ответ, урок идёт дальше. **«Пауза»** временно запрещает вопросы.

## 6. День занятия

**До урока (5 минут)**
1. Запустите сервер (раздел 3) и откройте пульт.
2. Выберите группу и занятие → **«Начать занятие»**.
3. С занятия 3: «🤖 Нейросеть» → «Проверить связь».
4. Откройте презентацию: двойной щелчок по `Презентация/presentation.html` (клавиша `N` — заметки докладчика).
   Сценарии и техкарты — материалы преподавателя, в эту папку не входят.

**На уроке**
1. Ученики открывают ярлык «Курс» и нажимают своё имя. На пульте в «Требует внимания» → **«Пустить всех»**.
2. Задания закрыты: открывайте их по шагам урока в карточке **«Ход урока»** (что когда открывать — на слайдах
   «Сами: задания…» и в сценарии).
3. Следите за «Прогрессом класса» и «Требует внимания» (вызовы «Позвать учителя»). Клетка таблицы — код ученика
   рядом с эталоном. «🖥 Проектор» — таймер и счёт сдавших без имён для большого экрана.

**Если ученик вставил чужой код** (из браузера, чата с нейросетью, подсказки) — его панель блокируется: экран
«🔒 Панель заблокирована», файлы только для чтения. Перезапуск VS Code не помогает — снять блокировку можете только вы:
«Требует внимания» → «Посмотреть» (что вставлял) → «Разблокировать». Выключить автоблокировку — галочка там же.

**После урока**
1. **«Завершить занятие»**: работы учеников сохраняются на сервере и стираются с их компьютеров. Пульт спросит,
   закрыть ли VS Code у учеников — «ОК», и через несколько секунд VS Code курса закроется на всех компьютерах.
   То же отдельно: кнопка **«⏻ Закрыть VS Code у всех»** (файлы перед закрытием сохраняются; открыть снова — ярлыком «Курс»).
   Завершили случайно или урок продолжается на следующей паре — на пульте **«⏯ Продолжить занятие»**: вернутся
   группа, занятие, открытые задания и этап, решённые задания и файлы учеников на месте.
2. Остановите сервер: `Ctrl+C` в окне терминала. Результаты можно выгрузить в CSV с пульта.

## 7. Если сервер — отдельный компьютер

Сервер можно запустить на любом компьютере в сети класса (например, на постоянно включённом ПК или сервере
под Linux) — команды те же, что в разделе 3. Пульт открывается только с самого этого компьютера, поэтому
с учительского ноутбука подключайтесь через SSH-туннель:

```bash
ssh -L 8000:localhost:8000 пользователь@адрес-сервера
```

Пока туннель открыт, пульт доступен на ноутбуке по адресу http://localhost:8000/teacher.

**Лучше запускать сервер под отдельным пользователем**, чтобы ученики не могли прочитать эталоны и данные:

```bash
sudo useradd -m kurs
```

```bash
sudo -u kurs python3 /путь/к/проекту/kurs/server/kurs_server.py
```

Чтобы сервер стартовал сам при включении (Linux, systemd), создайте `/etc/systemd/system/kurs.service`:

```ini
[Unit]
Description=Сервер курса «Чат-боты на Python»
After=network-online.target

[Service]
User=kurs
WorkingDirectory=/путь/к/проекту
ExecStart=/usr/bin/python3 kurs/server/kurs_server.py
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

и включите его: `sudo systemctl enable --now kurs`. Журнал: `journalctl -u kurs -f`.
Если сервер работает постоянно, порт 8000 открыт всё время — держите его только в сети класса.

## 8. Обновление

Одной командой в папке проекта — даже если сервер сейчас работает и идёт урок:

```bash
python3 update.py
```

Команда:
1. сохраняет копию данных сервера (группы, результаты, работы учеников, ключ нейросети) в `~/.kurs-server-backups/`;
2. скачивает обновление (`git pull`); если не получилось — старый сервер не трогает;
3. останавливает старый сервер и запускает новый в этом же окне (остановить — `Ctrl+C`);
4. просит панели учеников перезапустить VS Code и обновиться.

Урок при этом не прерывается: занятие, открытые задания, результаты и вход учеников остаются. Пульт после
перезапуска попросит ваш пароль. Только перезапустить сервер, без обновления: `python3 update.py --no-pull`.

Самый первый раз `update.py` ещё нет на компьютере — сначала `git pull`, потом `python3 update.py`.
Если скачивали ZIP, а не через git: скачайте новый ZIP, замените папку и запустите `python3 update.py --no-pull`.

**На ученических ПК делать ничего не нужно.** Панели перезапускаются и обновляются сами (с версии 0.2.0; в первый раз
после обновления до 0.2.0 ученики закрывают VS Code и открывают ярлык «Курс» сами). Перезапустить VS Code у всех
можно и вручную: кнопка **«🔄 Перезапустить VS Code у всех»** на пульте. Перезапустить VS Code только у одного
ученика (например, если у него что-то зависло): кнопка **🔄** рядом с его именем в таблице «Прогресс класса».

## 9. Если что-то не работает

| Что случилось | Что сделать |
|---|---|
| Ученический ПК не открывает адрес сервера (в терминале «Connection timed out» или команда подключения молчит) | Тот же Wi-Fi/сеть? Порт 8000 открыт в брандмауэре учительского ПК? Сервер запущен? |
| Команда подключения пишет «Не найден VS Code» | Установите VS Code; на Linux проверьте, что работает команда `code` |
| `python3` не найдена (Windows) | Используйте `py`; или переустановите Python с галочкой «Add python.exe to PATH» |
| Пульт не открывается | Открывайте именно http://localhost:8000/teacher на компьютере, где запущен сервер |
| Ученик не видит своё имя | Занятие начато для нужной группы? Имя есть в списке группы? |
| Ученик нажал имя, но ждёт | Подтвердите вход на пульте («Требует внимания» → «Пустить всех») |
| «Нейросеть не ответила» у всех | Пульт → «Проверить связь». Ошибка ключа — проверьте ключ; сертификата — раздел 5; нет интернета — «Запасной режим» |
| «Address already in use» / «Порт 8000 уже занят» | Скорее всего, сервер уже запущен в другом окне — просто откройте пульт. Перезапуск: `pkill -f kurs_server.py` (Linux/macOS) и запустить снова. Порт занят другой программой — `--port 8080` и переподключить ПК учеников командой с пульта |
| Забыли пароль пульта | `python3 kurs/server/kurs_server.py --reset-password` |
