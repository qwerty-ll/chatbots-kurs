## Запуск

В папке команды (нужен файл `.env`, в классе его создаёт панель курса):

```bash
python3 Наш_бот.py          # Windows: py Наш_бот.py
python3 Фамилия_И_.py       # только инструменты одного ученика
```

Структура папки команды такая же, как в экспорте: файлы учеников лежат и в корне (для запуска по одному),
и в `Команда/` (оттуда их собирает `Наш_бот.py`).
